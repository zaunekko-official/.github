## ここは ZaunEkko です

個人プロジェクト、クリエイティブな実験、そして長期的にメンテナンスしていくオープンソースの取り組みを置く場所です。

アイデアを必要以上に大きく見せるよりも、ここではひとつのことを大切にしています。**まず丁寧に完成させてから、その過程をきちんと伝えること。**
